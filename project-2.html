Overview

Rokall CUS is a real estate website built to showcase property listings and guide both buyers and investors toward an enquiry. The focus was a clean listing experience and a simple, low-friction journey from browsing to contact.

The challenge

Property websites can quickly become cluttered. The goal was to present listings attractively, let visitors find what is relevant to them, and keep the path to enquiry short for two different audiences — buyers and investors.

My approach

  • Designed a listing layout that puts photos, key details and the enquiry action up front.
  • Separated the buyer and investor journeys so each audience finds relevant information quickly.
  • Built fully responsive templates so listings read well on mobile, where most property browsing happens.
  • Tuned performance so image-heavy pages still load quickly.
